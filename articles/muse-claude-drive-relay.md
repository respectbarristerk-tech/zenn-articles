Metaのパーソナルエージェント「Muse」が日本で使えるようになりました。普段の入口をMuseに絞り、処理はClaudeに任せる構成を、Googleドライブのフォルダを介して試しました。

架空のレシートでの検証で、本番運用はこれからです。

## 構成

MuseとClaudeを直接つなぐのではなく、両方が読み書きできるフォルダをキューとして使います。

| 役割 | 担当 | 処理 |
|---|---|---|
| 処理 | Claude | レシートを読み取り、不明点を `question_NNN.txt` に書く |
| 通知 | Muse | 定時に未回答を探し、質問と画像を人に伝える |
| 判断 | 人 | Museに返答する |
| 書き戻し | Muse | 返答を `answer_NNN.txt` に保存する |
| 反映 | Claude | 回答を読んで台帳に反映する |

## ファイル形式

質問ファイルは次の形にしました。

```text
質問ID: 001
画像: test_receipt_001.jpg
店名: サンプル文具店
日付: 2026-11-02
読めなかった項目: 合計金額（かすれている）
AIの候補: 1,628円（明細4行の合計）
質問:
1. 合計金額は1,628円で合っていますか。
2. USBメモリ（880円）は副業用ですか、私用ですか。
状態: 回答待ち
```

回答ファイルはこの形です。

```text
質問ID: 001
質問1の回答:
質問2の回答:
回答日時:
状態: 回答済み
```

未回答の判定は「状態が回答待ち」かつ「同じ番号の `answer_` がない」の2条件です。質問ファイルは書き換えないので、書き手は1ファイルに1人だけになり、競合を避けられます。

## Museへの依頼文

```text
Googleドライブのフォルダ「（フォルダ名）」を確認してください。このフォルダ以外は開かないでください。

question_ で始まるファイルのうち、状態が「回答待ち」で、対応する answer_ ファイルがないものを探してください。見つかったら、質問の内容と関係する画像を私に伝えてください。見つからなければ、何も通知しないでください。

私が返答したら、同じ形式で answer_ ファイルを保存してください。
```

## 検証結果

| 項目 | 結果 |
|---|---|
| 質問の読み取りと伝言 | 成功 |
| 画像の表示 | 成功 |
| ぼかした金額の扱い | 「直接は読めない」と報告し、明細の合計と照合 |
| 回答の保存とClaudeでの読み取り | 成功 |
| 定時の確認とスマホ通知 | 1回成功 |
| 回答済み質問の除外 | 成功 |

実行時刻は、13:30の設定に対して13:27の時点で通知が届いていました。理由は不明です。人への通知なら少し早くても困りませんが、分単位の精度は前提にしないほうがよさそうです。

質問が1つのときは、Museが2問目の欄を「なし」で埋めました。形式を守る動きですが、質問数が変わる場合の書式は先に決めておくべきでした。

## 注意点

- Museの説明では、接続はGoogleアカウント単位で、フォルダ単位の権限制限はできません。依頼文の制限は運用上のルールで、技術的な境界ではありません
- 同じく、標準の環境では会話がAIの開発に使われることがあり、オプトアウトの設定があるとのことです。詳細は公式の案内を確認してください
- 上の機能説明の多くはMuse自身の回答です。実際に確かめたのは検証結果の表の範囲だけです
