## はじめに

個人で動かしている小さな自動売買bot（暗号資産の現物のみ・少額）の**日次運用をAI（Claude）に任せる**実験をしています。
AIの仕事は毎日決まった時間に「ログを読む → 異常がないか確認 → 改善を1つ進める → 日報を書く」こと。この記事は、その最初の1週間の開発記録です。

> 本記事は技術・運用の記録であり、投資の勧誘や助言ではありません。過去の結果は将来の成績を保証しません。

## 運用のルール

AIに任せるにあたり、最初に「やってよいこと／ダメなこと」を文章で決めました。

- 現物のみ。レバレッジ等は禁止
- 取引額の縮小・停止条件の追加など**安全側の小変更**はAIの判断で反映してよい
- 戦略ロジックの変更は、バックテストとペーパー（仮想売買）で優位性を確認してから
- 資金を新たに動かす操作（入金・本番切替など）は必ず人間の承認を待つ
- APIキーなどの秘密情報は読まない・出力しない
- 本番ファイルを変える前に必ずバックアップし、変更点を日報に書く

この「段階的な権限」がかなり効きました。AIが判断に迷う場面でも、ルールに照らして「これは提案止まり」と自分で線を引いてくれます。

## 発見1: 自動再起動が一度も成功していなかった

botには「止まっていたら起動し直す」監視スクリプトと、毎朝のメンテ後に再起動する仕組みがありました。ところがログを追うと、**再起動を試みるたびに失敗していた**ことが分かりました。

原因はWindowsの `start` コマンドの仕様です。

```bat
:: NG: 最初の引数がウィンドウタイトルではなく「実行するファイル名」と解釈される場合がある
cmd /c start mybot /min python main.py

:: OK: タイトルは必ずダブルクォートで渡す
cmd /c start "mybot" /min python main.py
```

`start` は**最初のダブルクォートで囲まれた引数**をウィンドウタイトルとして扱います。クォートなしで書くと、それが実行ファイル名と解釈され `The system cannot find the file mybot.` で失敗します。Pythonの `subprocess` から組み立てるときも同じで、タイトルを `'"mybot"'` のように渡す必要があります。

普段はbotが止まらないので、この不具合は**再起動が必要になった瞬間まで表に出ません**。「監視があるから安心」ではなく、監視の“復旧動作”そのものを一度わざと動かして確認するべきでした。

## 発見2: 「買える状態」になっていなかった

ペーパー運用から本番に切り替えた直後、AIは「シグナルが出ても注文できない」ことに気づきました。口座の資産のほとんどが、bot導入前から持っていた暗号資産で、日本円がほぼゼロだったためです。

このbotは、手動で持っている分を「管理外の保有」として記録し、**自分が建てたポジション以外には触らない**設計にしています（人の資産を勝手に売らないための安全装置）。その結果、

- 買いシグナル → 資金不足で注文エラー → そのバーは見送り

を繰り返すだけの状態でした。暴走はしない（同じバーで再試行しない）ことをAIがコードで確認したうえで、「資金をどう用意するか」は人間の判断事項として日報に上げてきました。最終的に人間が手動で整理し、botの「管理外保有」の記録を更新して解決しています。

**教訓:** 本番切替のチェックリストには「APIがつながる」だけでなく「戦略が想定する資金が実際に使える状態か」を入れる。

## 発見3: 稼働しているbotの“優位性”はほぼゼロだった

別のbot（DEXで売買するもの）は数か月動いていましたが、決済ベースの損益を集計すると**ほぼトントンからわずかなマイナス**。売買回数が多く、1回ごとの小さな負けが積み重なっていました。

そこでAIは、本番には手を入れずに**シャドーペーパー**（同じ価格データで別の戦略を仮想売買し続ける仕組み）を作り、候補戦略と並走させて比較しています。バックテストだけでなく、未来のデータで前向きに検証してから入れ替える方針です。

## AIに日次運用を任せてみた感想

- **良かった点**: 人間が見落とす「たまにしか動かない処理」の不具合をログから拾ってくる。判断理由とスキップした理由まで毎日文章で残るので、後から追える
- **注意点**: AIは外部サービスへの接続や資金移動の“実行”はしない前提にしておくと安心。権限の線引きを最初に文書化するのが一番大事
- **まだ分からない点**: 収益が出るかどうか。今のところ「壊れていないことを確かめる」価値が大きい段階です

続きは、ペーパー検証の結果が出たら書く予定です。
